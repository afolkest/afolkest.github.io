# Design Invariants

- Heliotrope is the only font
- The landing page should display the breadth of Aasmund's work, with links to
  individual pieces or pages displaying more of a worktype. 
- We should only prototype the home page
- Every design must contain the exact same words as the prototype, or fewer.
  None can be added
- The ethos extreme parseability and carefully constructed hierarchy,
  typography, alignment
- Previews upon hovering over contents (papers, artworks, etc) is allowed, even
  if their main presentation is on a separate page
- Design for desktop for now 

# Banned design elements
- Colored spines 
- Underlined links
- Dark background+white fonts
